# Ray Tracer

Проект на C++ - реализация рейтрейсера для рендеринга простых 3D-сцен. Рендерер поддерживает геометрические объекты, освещение, тени, отражения и преломления, а также загрузку сцен из файлов OBJ/MTL.

## Возможности

- Рендеринг 3D-сцен с помощью трассировки лучей.
- Поддержка треугольников и сфер.
- Загрузка геометрии, нормалей и материалов из OBJ/MTL-файлов.
- Модель освещения Фонга: ambient, diffuse и specular составляющие.
- Расчёт теней от точечных источников света.
- Рекурсивная трассировка отражённых и преломлённых лучей.
- Поддержка гладкого затенения с интерполяцией нормалей.
- Отладочные режимы визуализации глубины и нормалей.
- Tone mapping и gamma correction для обработки итогового изображения.

## Построение изображения

Рендеринг выполняется последовательно для каждого пикселя изображения:

1. Формируется положение камеры и виртуального экрана с учётом заданных параметров.
2. Через центр каждого пикселя проводится луч из камеры в сцену.
3. Определяется ближайшее пересечение луча с геометрическими объектами.
4. В точке пересечения рассчитывается освещение, учитываются тени и свойства материала.
5. При наличии отражающих или прозрачных поверхностей запускаются дополнительные рекурсивные лучи.
6. Полученный цвет проходит постобработку и записывается в соответствующий пиксель изображения.

## Реализованные алгоритмы

### Геометрия

- Векторные операции в трёхмерном пространстве.
- Скалярное и векторное произведения, вычисление длины вектора.
- Пересечение луча с треугольником по алгоритму Мёллера-Трумбора.
- Пересечение луча со сферой.
- Вычисление барицентрических координат.
- Расчёт нормалей и площади треугольников.

### Освещение и оптические эффекты

- **Ambient** - фоновая составляющая освещения материала.
- **Diffuse** - рассеянное освещение с учётом угла между нормалью поверхности и направлением на источник света.
- **Specular** - зеркальный блик, зависящий от положения камеры, источника света и параметров материала.
- **Shadows** - проверка видимости источника света с помощью теневых лучей.
- **Reflection** - построение отражённого луча с рекурсивным расчётом освещения.
- **Refraction** - построение преломлённого луча с учётом показателя преломления среды.

### Постобработка

- **Tone mapping** - приведение интенсивности цветов к диапазону, необходимому для сохранения изображения.
- **Gamma correction** - нелинейное преобразование цветов для корректного отображения итогового изображения.

## Структура проекта

Проект разделён на модули, каждый из которых отвечает за отдельную часть рендерера.

| Модуль | Описание |
|---|---|
| `raytracer-geom` | Геометрические примитивы, векторы, лучи, пересечения и геометрические вычисления. |
| `raytracer-reader` | Чтение OBJ/MTL-файлов, хранение геометрии, материалов и источников света сцены. |
| `raytracer-debug` | Отладочные режимы визуализации глубины и нормалей. |
| `raytracer` | Основной алгоритм рендеринга, камера, освещение, тени, отражения, преломления и постобработка. |

## Форматы сцен

### OBJ

Поддерживаются:

- `v` - координаты вершин;
- `vn` - нормали вершин;
- `f` - полигоны, которые преобразуются в треугольники;
- `mtllib` - подключение файла материалов;
- `usemtl` - назначение материала объекту;
- `S` - сферы;
- `P` - точечные источники света.

Для полигонов поддерживаются различные варианты записи индексов вершин, нормалей и текстурных координат. Текстурирование при этом не реализуется.

### MTL

Поддерживаются параметры материалов:

| Параметр | Описание |
|---|---|
| `newmtl` | Название материала |
| `Ka` | Ambient color |
| `Kd` | Diffuse color |
| `Ks` | Specular color |
| `Ke` | Emissive intensity |
| `Ns` | Specular exponent |
| `Ni` | Refractive index |
| `al` | Коэффициенты отражения, преломления и локального освещения |

## Параметры рендеринга

Основная точка входа - функция `Render()`:

```cpp
Image Render(
    const std::filesystem::path& path,
    const CameraOptions& camera_options,
    const RenderOptions& render_options
);
```

- `path` - путь к файлу сцены `.obj`.
- `camera_options` - положение и направление камеры, поле зрения и разрешение изображения.
- `render_options` - параметры трассировки, включая глубину рекурсии и режим рендеринга.

Поддерживаются три режима:

| Режим | Описание |
|---|---|
| `kFull` | Полноценный рендеринг с освещением и оптическими эффектами. |
| `kDepth` | Визуализация расстояния от камеры до ближайшей точки пересечения. |
| `kNormal` | Визуализация нормалей поверхности. |

## Сборка и тестирование

Для работы с проектом необходимы C++-компилятор, CMake и библиотека `libpng`.

Установка зависимости на Ubuntu:

```bash
sudo apt-get install libpng-dev
```

На macOS:

```bash
brew install libpng
```

Сборка выполняется в рамках предоставленной учебной инфраструктуры CMake. После конфигурации проекта можно собрать тестовые цели:

```bash
cmake --build build
```

Запуск тестов:

```bash
ctest --test-dir build --output-on-failure
```

Для запуска отдельного теста рендеринга:

```bash
./test_raytracer_asan "Box with spheres"
```

Тесты проверяют геометрические вычисления, чтение сцен и корректность рендеринга, сравнивая полученные изображения с эталонными. Проверка предусмотрена в конфигурациях AddressSanitizer и `RelWithDebInfo`.
